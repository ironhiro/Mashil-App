## 1. 원칙

- **소재 하나에서 출발한다:** 욕실 타일. 정사각 칸, 1px 줄눈, 6px 모서리. 장식은 이 소재에서만 가져온다.
- **청록 한 색조**를 밝기만 달리해서 쓴다. 두 번째 강조색은 두지 않는다.
- **청록은 "지금 열림"과 화면당 주 행동 버튼 1개(길찾기, N곳 보기, 다시 확인)에만 쓴다.** 선택 상태(필터, 세그먼트)는 무채색(먹색 또는 밝은 회색)으로 표시한다.
- **상태는 색에만 의존하지 않는다:** 채움, 진한 채움, 점선 테두리, 회색 테두리로 4단계를 구분한다.
- **정보 위계는 거리 숫자 → 이름 → 상태 → 시설** 순서로 고정한다. 위계는 장식이 아니라 숫자 크기로 만든다.
- **쓰지 않는 것:** 그라데이션 배경, 글래스모피즘, 이모지 아이콘, 카드 왼쪽 컬러 띠, 부드러운 큰 그림자, 모든 요소에 같은 큰 radius.

| 토큰 | 라이트 | 다크 | 용도 |

| `surface-sunken` | `#D7E8E5` | `#161718` | 지도 바탕, 정보없음 타일 |
| `line` | `#C3DCD8` | `#2A2C2F` | 줄눈, 구분선, 테두리 |
| `text` | `#0E3B3A` | `#ECECEC` | 본문 |
| `text-muted` | `#2F6F6B` | `#9A9DA3` | 보조 텍스트 |
| `accent` | `#1F6F69` | `#5CC2B7` | 열림 상태, 로고 글자 |
| `on-accent` | `#FFFFFF` | `#0B1F1D` | accent 위 글자 |
| `accent-soft` | `#CFE3E0` | `#23403D` | 곧 닫힘 타일 |
| `selected` | `#0E3B3A` / 글자 `#FFFFFF` | `#ECECEC` / 글자 `#111213` | 선택된 필터 |

## 3. 상태 표현 (타일 4단계)

| 상태 | 라이트 | 다크 |

| 정보없음 / 불규칙 / 건물 운영시간 | `surface-sunken` + `line` 1px | 동일 |

## 6. 앱 아이콘: 열린 문

**컨셉:** 살짝 열린 문틈으로 빛이 새고, 바닥에도 빛이 번진다. 슬로건 "잠깐, 다녀와"를 그림으로 옮긴 것이다.

| 요소 | 값 |
|---|---|
| 바탕 | `#1F6F69` (C의 주 청록). 원안 `#0E3B3A`는 다크 홈 화면에서 경계가 약해서 한 단계 밝혔다 |
| 문틈 빛 | `#7FE0D3` |
| 문짝 | `#FFFFFF` |
| 손잡이 | 바탕색 |
| 바닥 빛 | `#7FE0D3` 35% (60px 이상에서만) |
| 그리드 (100 단위) | 문틀 x33 y22 w34 h58 · 문짝 (33,22) (55,28) (55,75) (33,80) · 손잡이 (50,53) r2.8 |

**크기별 단순화:**
- 60px 이상: 전체 요소
- 40px: 바닥 빛 제거
- 29px 이하: 손잡이 제거, 문을 약간 키움
- 16px (파비콘): 문틀 radius 제거

**플랫폼 변형:**

| 플랫폼 | 내용 |
|---|---|
| iOS 기본 | 1024×1024, 위 사양 |
| iOS 다크 | 바탕 `#1B1C1E`, 빛 `#5CC2B7`, 문 `#ECECEC` |
| iOS 틴트 | 회색 2단계 (빛 `#8C8C8C`, 문 `#E0E0E0`) |
| Android 적응형 | 전경 = 문과 빛을 안전 영역(지름 66/108) 안에 들어가도록 82%로 축소. 배경 = `#1F6F69` 단색 |
| Android 테마 아이콘 (13+) | 단색: 문짝 채움 + 문틀 3px 외곽선 |

**앱 안에서 재사용:** 스플래시 화면 중앙, 그리고 지도의 "지금 열림" 마커에 단순형 문 글리프를 넣는다. 아이콘의 "열린 문"과 앱의 "열림" 상태가 같은 기호가 된다.

## 7. 화면별 결정 (캔버스 3행)

| 화면 | 결정 |
|---|---|
| **상세** | 상단에 지도 띠(168px)와 뒤로·공유 버튼. 거리 타일과 상태 타일을 나란히 놓는다. **개방시간은 요일 8칸 타일**(월~일 + 휴일)로 보여주고 오늘을 굵은 테두리로 강조한다. 아래에 묶음 표(월–금 / 토–일 / 공휴일)와 **원문**을 함께 표시한다 (정규화 결과를 사용자가 검증할 수 있게). 시설은 4칸 타일, 편의시설은 칩(없는 항목은 취소선). 평점·댓글 한 줄, 출처와 "정보 수정 요청" 링크. 하단 고정 바: 전화(아이콘) + 길찾기(주 행동) |
| **로그인** | 아이콘, 로고 글자, 슬로건 아래에 로그인으로 할 수 있는 일을 한 문장으로 설명한다. Kakao·Google·Apple 버튼은 **같은 높이(52px)와 같은 폭**으로 둔다 (Apple 4.8). "로그인 없이 둘러보기"를 항상 노출. 약관 동의는 첫 로그인 때 한 번만 받는다고 안내 |
| **필터 시트** | 개방 상태(세그먼트 3개), 시설(2×2 타일 토글), 편의시설(칩), 검색 반경(세그먼트 5개), 구분(칩, 선택 안 하면 전체). 하단에 초기화 + **"N곳 보기"**(결과 수를 실시간 반영) |
| **점검** | 아이콘의 문이 **닫힌** 상태 (빛 대신 문 아래 틈만). "문이 잠시 닫혔어요" + 다시 여는 시각. 급한 사용자를 위해 **카카오맵 열기** 대안을 제공한다. 주 행동은 "다시 확인" |

| **약관 동의** | 첫 로그인 직후 한 번. 표시 이름(IdP 닉네임 기본값, 수정 가능) + "모두 동의" + 필수 3종(이용약관, 개인정보 수집·이용, 위치기반서비스 이용약관), 각 항목 옆 보기 링크. **"위치 정보는 찾을 때만 쓰고 저장하지 않아요"**를 별도 안내 칸으로 둔다 (NFR-06). 필수 3종이 모두 체크되고 이름이 있어야 시작 버튼이 활성화 |
| **댓글·신고** | 내 평가는 **5칸 타일**(별 대신 타일 모티프), 평균과 인원. 댓글마다 ⋮ 메뉴. 신고로 가려진 댓글은 점선 칸으로 표시. 신고 시트: 대상 댓글 인용 → 사유 4종(라디오) → "이 사용자 댓글 보지 않기(차단)" 체크 → 자동 가림 정책 안내 → 취소 / 신고하기 (사유를 골라야 활성화) |
| **계정 삭제** | 지워지는 것(채움 칸) / 남는 것(테두리 칸) / 되돌릴 수 없는 것(`danger` 점선 칸)을 3단으로 구분. 확인 체크 후 **"카카오로 확인하고 삭제"** (IdP 재인증, USR-03). 보조 버튼은 "계정 유지하기" |
| **읽기 전용 점검** | 검색창 아래 먹색 배너: "찾기는 그대로 돼요 · 평가·댓글은 05:00까지 쉬어요". 배너의 작은 아이콘은 **반쯤 닫힌 문**. 시트 하단에 잠금 안내 칸 (OPS-05) |
| **다크 (3행 4종)** | 다크 토큰 그대로 적용. 선택 상태는 밝은 회색 채움, 주 행동은 `#5CC2B7` + 진한 글자. 로그인 버튼은 다크 변형 (Google 다크 스타일, Apple 흰 버튼). 점검 화면 아이콘 바탕은 `#23403D` |

**아이콘 문의 세 상태:** 열린 문(앱 아이콘, 열림 마커) / 반쯤 닫힌 문(읽기 전용 점검) / 닫힌 문(전체 점검). 같은 기호의 열림 정도로 서비스 상태를 표현한다.

**로그인 버튼 주의:** 시안의 K·G·A 자리는 자리표시자다. 실제 구현에서는 각 사가 배포하는 **공식 로고와 버튼 가이드**(Kakao 로그인 디자인 가이드, Google Sign-In 브랜딩 가이드, Apple Sign in with Apple HIG)를 따르고, 색과 문구도 가이드에서 허용하는 값만 쓴다.
