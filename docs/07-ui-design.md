## 1. 원칙

- **소재 하나에서 출발한다:** 역과 길에 붙은 공공 안내판. 3미터 밖에서 한눈에 읽혀야 한다. 정사각 칸, 2px 잉크 테두리, 고정폭 글자. 장식은 이 소재에서만 가져온다.
- **색은 셋뿐이다:** 회청색 종이, 청흑 잉크, 그리고 신호 두 개. **코발트는 "지금 열림"과 화면당 주 행동 1개**(길찾기, N곳 보기, 다시 확인)에만, **앰버는 잉크 위의 숫자**와 "곧 닫힘"에만 쓴다. 앰버 글자를 종이 위에 쓰지 않는다.
- **선택 상태는 잉크 칸이다:** 필터와 세그먼트에서 고른 칸은 잉크로 채우고 종이색 글자를 쓴다. 코발트는 선택에 쓰지 않는다.
- **상태는 색에만 의존하지 않는다:** 채움, 앰버 채움, 잉크 테두리, 회색 머리카락 선으로 4단계를 구분한다 (§3).
- **정보 위계는 거리 숫자, 이름, 상태, 시설** 순서로 고정한다. 위계는 장식이 아니라 숫자 크기와 굵기로 만든다.
- **깊이는 테두리로 낸다:** 모서리 0, 그림자 없음. 상태 알약(pill)만 둥글게 할 수 있다.
- **쓰지 않는 것:** 그라데이션, 글래스모피즘, 이모지 아이콘, 둥근 카드, 부드러운 그림자, 가운뎃점으로 이은 메타 문구, 글자에 붙인 화살표, 대시(—).

## 3. 상태 표현 (4단계)

서버 판정(`openStatus`: 한국 시간·요일·공휴일·자정 넘김 반영)을 쓴다. 정규식 판정은 목업 데이터용 대체 경로다.

| 상태 | 표현 | 짧은 표기 |
|---|---|---|
| 지금 열림 / 24시간 | 코발트 채움, 흰 글자 | `22:00까지`, `24시간` |
| 곧 닫힘 (30분 이내) | 앰버 채움, 잉크 글자 (안내판의 "늦음" 행처럼) | `22:00까지` |
| 종료 / 미개방 | 종이 바탕 + 2px 잉크 테두리 | `종료` (자세히: "내일 09:00에 열려요") |
| 정보없음 / 불규칙 / 건물 운영시간 | 회색 종이 + 머리카락 선, 흐린 글자 | `정보없음` |

같은 규칙을 지도 마커, 근처 안내판, 상세의 상태 판, 요일 칸에 쓴다 (`app.css` 의 `.state--live / soon / closed / unknown`).

## 4. 서체

| 용도 | 서체 | 비고 |
|---|---|---|
| 모든 글자 (제목, 본문, 숫자, 버튼) | Chivo Mono 400 / 500 / 800 | 안내판의 고정폭 글자. 비례 서체는 쓰지 않는다 |
| 한글 | Nanum Gothic Coding 400 / 700 | Chivo Mono 에 한글이 없어 같은 고정폭 한글로 잇는다 |

- 제목 800, 자간 -0.03em. 라벨·표 머리·알약은 500 한 단계 작게, 문장형(대문자 없음).
- 숫자는 `tabular-nums`. 거리와 시각은 800, 잉크 위 앰버.

## 5. 형태

| 항목 | 값 |
|---|---|
| 모서리 | 0 (알약만 999px) |
| 테두리 | 면의 테두리 2px 잉크, 행 구분 1px `rule` |
| 버튼 | 주 행동 코발트 채움, 보조는 투명 + 2px 잉크 테두리. 높이 52px (촘촘한 줄 44px) |
| 선택 묶음 | 2px 테두리를 공유하는 정사각 칸들. 고른 칸은 잉크 채움 |
| 입력창 | 정사각, 2px 잉크 테두리, `paper-3` 바탕. 포커스는 테두리가 아니라 코발트 outline |
| 움직임 | 색 변화는 `steps(1)` 로 끊어서 (안내판처럼). 등장 애니메이션 없음 |
| 터치 영역 | 최소 44px |

**공통 부품** (`app.css`):

- **판(plate):** 잉크 띠 위에 지시 하나와 그 숫자. 거리 판(앰버 숫자), 상태 판(상태 색), 점검의 다시 여는 시각.
- **근처 안내판(board):** 출발 안내판처럼 한 행에 거리(앰버), 이름과 시설, 오른쪽 끝 상태. 시그니처.
- **칸(cells):** 테두리를 공유하는 정사각 칸. 요일 8칸, 시설 4칸.

## 6. 앱 아이콘: 열린 문

**컨셉:** 살짝 열린 문틈으로 빛이 새고, 바닥에도 빛이 번진다. 슬로건 "잠깐, 다녀와"를 그림으로 옮긴 것이다. 화면 테마(Wayfind)와 별개인 **브랜드 자산**이라 청록을 유지한다.

| 요소 | 값 |
|---|---|
| 바탕 | `#1F6F69`. 원안 `#0E3B3A`는 다크 홈 화면에서 경계가 약해서 한 단계 밝혔다 |
| 문틈 빛 | `#7FE0D3` |
| 문짝 | `#FFFFFF` |
| 손잡이 | 바탕색 |
| 바닥 빛 | `#7FE0D3` 35% (60px 이상에서만) |
| 그리드 (100 단위) | 문틀 x33 y22 w34 h58, 문짝 (33,22) (55,28) (55,75) (33,80), 손잡이 (50,53) r2.8 |

**크기별 단순화:**
- 60px 이상: 전체 요소
- 40px: 바닥 빛 제거
- 29px 이하: 손잡이 제거, 문을 약간 키움
- 16px (파비콘): 문틀 radius 제거

**플랫폼 변형:**

| 플랫폼 | 내용 |
|---|---|
| iOS 기본 | 1024×1024, 위 사양 |
| iOS 다크 | 바탕 `#1B1C1E`, 빛 `#5CC2B7`, 문 `#ECECEC` (미구현) |
| iOS 틴트 | 회색 2단계 (빛 `#8C8C8C`, 문 `#E0E0E0`) (미구현) |
| Android 적응형 | 전경 = 문과 빛을 안전 영역(지름 66/108) 안에 들어가도록 82%로 축소. 배경 = `#1F6F69` 단색 |
| Android 테마 아이콘 (13+) | 단색: 문짝 채움 + 문틀 3px 외곽선 |

생성기: `app/tool/make_icons.py`. 스플래시는 바탕색(`paper`) 위에 문 글리프만 (라이트에서는 청록 외곽선 글리프: 흰 문이 밝은 바탕에 묻혀서).

**문의 세 상태:** 열린 문(앱 아이콘) / 반쯤 닫힌 문(읽기 전용 점검) / 닫힌 문(전체 점검). 같은 기호의 열림 정도로 서비스 상태를 표현한다.

## 7. 화면별 결정

| 화면 | 결정 | 상태 |
|---|---|---|
| **홈** | 제목, 필터 버튼(조건 수와 반경), 지도·목록 전환. 지도는 상태 안내판 조각 마커와 코발트 점선 반경 원, 내 위치 점. 목록은 **근처 안내판**. 행을 누르면 상세로 | 구현 |
| **상세** | 지도 띠(168px)와 뒤로·공유. **거리 판과 상태 판을 나란히** (상태 판 둘째 줄은 "닫기까지 3시간 12분"처럼 새 정보). **개방 시간은 요일 8칸**(월~일 + 휴일), 오늘은 잉크 칸에 "오늘". 묶음 표(월~금 / 토, 일 / 공휴일)와 **원문**을 함께 (정규화 결과를 사용자가 검증할 수 있게). 시설 4칸, 편의시설(없는 항목은 취소선). 평점·댓글, 출처와 "정보 수정 요청". 하단 고정 바: 전화(아이콘) + 길찾기(주 행동) | 구현 |
| **로그인** | 아이콘, 로고, 슬로건, 로그인으로 할 수 있는 일 한 문장. Kakao·Google·Apple 버튼은 **같은 높이(52px)와 같은 폭** (Apple 4.8). "로그인 없이 둘러보기" 항상 노출. 약관 동의는 첫 로그인 때 한 번만 받는다고 안내 | 구현 (공식 로고 미적용) |
| **필터 시트** | 개방 상태(전체 / 지금 열림 / 24시간), 시설(2×2 칸), 검색 반경(500m~5km), 구분(선택 안 하면 전체). 하단 초기화 + **"N곳 보기"**(결과 수 실시간). 편의시설은 `/near` 응답에 필드가 생기면 추가 | 구현 (편의시설 제외) |
| **점검** | 닫힌 문, "문이 잠시 닫혔어요", 다시 여는 시각은 판(잉크 위 앰버). 주 행동 "다시 확인", 대안으로 **카카오맵에서 화장실 찾기**. `GET /api/app/status` 의 `maintenance` | 구현 (웹) |
| **읽기 전용 점검** | 상단에 **앰버 띠**(늦음 행처럼) + 반쯤 닫힌 문: "찾기는 그대로 돼요. 평가, 댓글, 제보는 05:00까지 쉬어요." 평점·댓글 입력은 숨긴다 | 구현 (웹) |
| **약관 동의** | 첫 로그인 직후 한 번. 표시 이름(IdP 닉네임 기본값, 수정 가능) + "모두 동의" + 필수 3종(이용약관, 개인정보 수집·이용, 위치기반서비스 이용약관), 각 항목 옆 보기 링크. **"위치 정보는 찾을 때만 쓰고 저장하지 않아요"**는 별도 판으로 (NFR-06). 필수 3종과 이름이 있어야 시작 버튼이 켜진다 | 구현 (약관 본문 없음) |
| **댓글·신고** | 내 평가는 **5칸**(테두리를 공유하는 칸, 고른 만큼 잉크), 평균과 인원. 댓글마다 ⋮ 메뉴. 신고로 가려진 댓글은 회색 칸. 신고 시트: 대상 댓글 인용, 사유 4종(라디오), "이 사용자 댓글 보지 않기(차단)", 자동 가림 정책 안내, 취소 / 신고하기 (사유를 골라야 켜짐) | 미구현 (지금은 별점) |
| **계정 삭제** | 지워지는 것(잉크 판) / 남는 것(테두리 칸) / 되돌릴 수 없는 것(`error` 테두리 칸)을 3단으로. 확인 체크 후 **"카카오로 확인하고 삭제"** (IdP 재인증, USR-03). 보조 버튼 "계정 유지하기" | 미구현 |
| **다크** | night 색으로 자동 전환. 안내판과 판은 어두운 띠 그대로, 선택 칸은 밝은 잉크. 로그인 버튼은 각 사 다크 변형 | 구현 (로그인 다크 변형 제외) |

**로그인 버튼 주의:** 실제 출시 전에는 각 사가 배포하는 **공식 로고와 버튼 가이드**(Kakao 로그인 디자인 가이드, Google Sign-In 브랜딩 가이드, Apple Sign in with Apple HIG)를 따르고, 색과 문구도 가이드에서 허용하는 값만 쓴다.

욕실 타일에서 출발한 방향이었다: 청록 한 색조(`#1F6F69`, 다크 `#5CC2B7`), 연한 청록 바탕(`#E8F2F0`), 6px 모서리, 1px 줄눈 격자, 점선 테두리로 종료 표시, 로고는 Gowun Dodum, 본문 IBM Plex Sans KR, 숫자 DM Mono. 1·2단계로 구현했다가 Hallmark 재설계에서 Wayfind 로 바꿨다. 그대로 이어받은 것: 상태 4단계라는 구조, 정보 위계(거리, 이름, 상태, 시설), 화면별 구성(§7), 앱 아이콘(§6). 시안은 위 캔버스에 남아 있다.
